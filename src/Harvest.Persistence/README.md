# Persistence disk API (SAVE-01)

Targets netstandard2.1, C# 9. System.Text.Json is exactly pinned; NuGet lock files pin the transitive graph. Tests are a dependency-free net10.0 executable: `dotnet run --project tests/Persistence/Persistence.Tests.csproj` (a nonzero exit means failure).

`SaveEnvelope.Create(simulationVersion, contentVersion, payloadJson)` builds v1 disk envelopes; `Encode` / `Decode` bound files to 16 MiB, JSON depth to 64, require strict UTF-8, reject duplicate keys recursively and unknown/missing envelope keys, and validate exact payload UTF-8 length and SHA-256. Payload is a JSON string in the outer envelope to avoid reserialization ambiguities. A checksum detects corruption; it is not authentication. Schema migrations are not yet needed; non-v1 schemas are rejected and existing future-version saves cannot be overwritten. Full stopped-session schema/compatibility validation belongs in the forthcoming published Domain/Application adapter.

`AtomicSlotStore(existingDirectory, validatePayload, optionalFiles)` requires a complete payload validator. `Save(slot,envelope)` validates before writes and after rereading the flushed exclusive temp; backs up validated existing primary via flushed temp and atomic replacement, then atomically installs primary. A corrupt primary never replaces a good backup. `Load(slot)` returns a validated primary, or an error code plus explicit validated recovery candidates and rejected-candidate diagnostics. `ReadRecovery(slot,candidatePath)` revalidates an explicitly selected artifact. There is no live-session mutation, automatic temp promotion, or script execution. Slot names are simple identifiers. Application separates campaign/sandbox directories. The directory is trusted application-selected storage, not an untrusted player-selected path; symbolic-link containment is not provided.

All store instances in a process serialize operations for the same normalized directory. Use one application process per save directory; cross-process writer coordination is not provided. Up to 64 temp recovery artifacts are scanned; an overflow diagnostic is returned while preserving the valid backup recovery option. Archive obsolete files explicitly after choosing recovery. Temps are intentionally retained after failed writes. A primary is authoritative even if a newer orphan temp exists.

`ISlotFiles` provides exclusive write/flush, bounded reads and atomic installation for fault injection. Physical implementation uses FileStream.Flush(true), File.Replace when destination exists, and File.Move otherwise, in the same directory. No copy-overwrite fallback. macOS primitives are exercised by tests; Windows verification remains pending. Directory fsync is unavailable through this portable adapter: successful save means flushed file plus atomic replacement, not a promise of directory-entry survival after power loss. I/O failure after the final replacement can leave the new primary installed; inspect Load before retrying. Fault tests cover before/after all four write/replace steps, first-save orphan recovery, partial writes, corrupted flushed temps and excess recovery artifacts.

`PayloadLimits` enforces 64 KiB UTF-8 per script, 1 MiB aggregate source, and 64 KiB save-local editor state. The adapter must call it and allowlist editor fields. Global audio/accessibility preferences belong outside the stopped save. Domain owns world invariants/RNG/scheduler restoration; Application owns stopped snapshot capture/transactional restore. These interfaces are not invented by this disk module.

`DomainWorldCodec.EncodeStopped(WorldSnapshot)` / `DecodeStopped(worldJson, expectedRules)` maps the actual published Domain contract to an explicit v1 world schema. It preserves integer ticks, uint32 RNG state/algorithm, scheduler actor ID, tile state, depot stocks, tractor capacities and last-processed request sequences. RequestSequenceState is derived by Domain from serialized tractors rather than persisted redundantly. Decode uses constructor validation; no duplicated occupancy/resource/growth rules and no live mutation. Pending actions are excluded, active snapshots rejected. Serialized rule version and every numeric action/growth rule must exactly match the caller's currently validated rules; a forged same-version configuration is rejected rather than changing gameplay. The adapter does not invent seed/entity-allocator fields absent from the published world contract. Full session mode, scripts, policy and editor state mapping awaits Application DTO publication.

`StoppedSessionCodec(rules, simulationId, contentId)` completes the Application adapter. `Encode(StoppedSessionSnapshot)` returns an envelope; `Decode(SaveEnvelope)` returns a newly constructed immutable stopped DTO only after all nested schema, world, compatibility, scripts and selection checks succeed. `CreateStore(existingModeDirectory, expectedMode)` wires full validation into disk operations and rejects the other mode; callers supply separate mode directories. Explicit v1 session fields are mode, chapter, world, inert draft/actor assignments and save-local editor selectedActorId. Unsupported modifiers/global settings/execution data are rejected. Decode does not apply anything to a live session; Application must use its validated transactional restore contract. The actual shared DTO has no original seed or extra editor preferences, so the schema does not invent them. Malformed player syntax remains recoverable text.
