# Starting content and composition

Chief owns this module and Unity `Assets/Harvest/Bootstrap`, plus cross-module checks in `tests/Integration`. `FirstFarm.Create` returns a fresh validated stopped session for either mode. A 6×6 field, one tractor, wheat and a depot use the published Domain rules. The starter script runs through Language/Application; no content-specific completion or resource mutation occurs here. Campaign and sandbox are separate snapshots with stable simulation/content identifiers for save compatibility.
