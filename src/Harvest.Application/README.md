# Application contracts

`StoppedSessionSnapshot(mode, simulationId, contentId, world, campaignChapter, scripts, selectedActorId)` is the public immutable stopped payload for Persistence. `ScriptAssignment(actorId,draft)` holds inert source. Construction validates bounds, unique existing actor assignments, selection, stopped world and chapter range. Domain validates world/RNG/cursor/request sequences. Chapter 0 teaches sequential APIs; chapter 1 adds counted loops. Sandbox chapter is 0 and every supported language feature is granted. No sandbox modifiers are implemented in this spike; adapter must reject unsupported ones. Global audio/accessibility preferences are excluded.

SessionController capture will Stop then create this DTO. Restore validates compatibility before calling ISimulation.RestoreStopped, whose contract validates before replacing; Application then replaces scripts/policy and leaves execution Stopped. Persistence owns JSON and I/O; Application never references concrete Persistence.

`SessionController` uses a 10 Hz bounded pump (8 ticks/frame, discarding excess backlog); paused frames discard elapsed time and Step calls one tick. Completed programs clear their continuation while the running simulation can continue growth; controls remain explicit. Runtime faults stop the session with diagnostics. Active source is separate from editable draft. Gateway emits one validated actor proposal with a Domain-derived request ID; terminal results are routed on the next pass. Chapter 0 completion requires an authoritative successful unload event and an increase in depot wheat (pre-existing stock or an empty unload does not complete it), granting chapter 1 counted-loop capabilities. This is the spike objective; later data-driven chapters remain out of scope.

`LanguageProgramFactory` compiles/starts the real safe Language implementation and maps RunSlice. IProgramFactory/IProgramDriver permit tests at the interpreter composition seam without inventing gameplay. Restore prepares replacement drafts then invokes Domain's validated transactional restore before discarding execution. Capture uses StopAtBoundary, never an extra tick. Presentation ApplicationSessionView retains distinct stopped snapshots per mode; save disk namespaces are external wiring.
